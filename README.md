# synthwave

An 80s synthwave look for Claude: a striped sunset over a drifting neon city, with blurred water reflections, rolling mountains, a Challenger-style car on an elevated highway, street lights, flying birds and twinkling stars.

- Dark purple/pink theme with neon accents and frosted panels over the animated backdrop.
- Everything is vector and animated with CSS, and it slows to a still scene for people who ask for reduced motion.
- The look draws in the Claude desktop and mobile apps. The terminal and editor extensions draw no theme.

## Install

At the prompt of a terminal session:

```
/plugin install synthwave --marketplace RVillani/claude-theme-synthwave
```

From a shell:

```
claude plugin install synthwave --marketplace RVillani/claude-theme-synthwave
```

In the desktop app, where `/plugin` does not run: click + next to the prompt box, then Plugins, Add marketplace with `RVillani/claude-theme-synthwave`, then Add plugin.
